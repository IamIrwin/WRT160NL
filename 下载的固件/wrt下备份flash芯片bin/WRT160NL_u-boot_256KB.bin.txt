0x000000 ┌─────────────────────┐
          │ U-Boot              │ 256 KB
0x040000 ├─────────────────────┤
          │ kernel / firmware   │
          │                     │
0x7E0000 ├─────────────────────┤
          │ nvram               │ 64 KB
0x7F0000 ├─────────────────────┤
          │ ART                 │ 64 KB
0x800000 └─────────────────────┘
